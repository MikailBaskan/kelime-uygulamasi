# Kelime Kartpostalı 🗂️

İngilizce kelimeleri görsel hafıza ve aralıklı tekrar (flashcard) yöntemiyle öğrenmeyi sağlayan, PWA (Progressive Web App) tabanlı bir kelime öğrenme uygulaması. 

## Özellikler ✨

*   **Kelime Ekleme:** İngilizce kelimeleri ve Türkçe anlamlarını kolayca kaydedin.
*   **Görsel Hafıza:** Kelimelere galeriden özel fotoğraflar ekleyin. Fotoğraf seçilmezse otomatik olarak ilgili bir emoji/ikon atanır.
*   **Aralıklı Tekrar (Spaced Repetition):** Kartları sağa kaydırarak (öğrenildi) kuyruktan çıkarın veya sola kaydırarak (tekrar et) ileride tekrar karşınıza çıkmasını sağlayın.
*   **İstatistik Takibi:** Toplam kart sayısı, tekrar sayısı, genel başarı yüzdesi ve en çok zorlanılan kelimeleri anlık olarak görüntüleyin.
*   **Veri Kalıcılığı:** Tüm verileriniz (kelimeler, fotoğraflar ve istatistikler) cihazınızın yerel depolamasında (Local Storage) güvenle saklanır, internet gerektirmez.
*   **PWA Desteği:** Bir web uygulaması olmasının yanı sıra, Android cihazlara native bir uygulama gibi kurulabilir (.aab formatına dönüştürülerek Play Store'da yayınlanmaya uygundur).

## Kurulum ve Kullanım 🚀

Uygulama tamamen istemci tarafında (client-side) çalışmaktadır. Herhangi bir sunucu kurulumuna ihtiyaç yoktur.

1.  Bu depoyu bilgisayarınıza indirin veya klonlayın:
    `git clone https://github.com/MikailBaskan/kelime-kartpostali.git`
2.  Klasör içindeki `index.html` dosyasını herhangi bir modern web tarayıcısında (Chrome, Firefox, Edge vb.) açın.
3.  Veya GitHub Pages üzerinden yayınlanmış canlı bağlantıyı ziyaret ederek hemen kullanmaya başlayın.
